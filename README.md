# 임시표 마법 공방 · CHARM

첨부된 『임시표 마법 공방』 설계서 v1.0(2026-11-19)을 기반으로 구현한 모바일 음악이론 게임입니다.

## 실행

`index.html`을 브라우저로 열면 실행됩니다. 인터넷 연결이나 별도 설치가 필요하지 않습니다. 소리는 최초 클릭 후 재생됩니다. 소리가 없어도 모든 판단 문제를 풀 수 있습니다.

- 작업일 0~7단, 의뢰 66개, 오개념 모델 19개
- 기호 이름·시소·건반·표 붙이기·효력·까닭·곡선·수리의 8개 의뢰 유형
- 판단 → 차례 연주(해당 의뢰) → 납품
- 한 번 틀리면 원인 안내, 두 번 틀리면 답 제공 후 확정
- 틀린 의뢰는 3문항 뒤 다시 제시, 다음 작업일 복습은 최대 2개
- 80% 이상 첫 판단 정답이면 다음 단계 해금. 연주는 통과 조건과 별도로 기록
- 발견 장면 7개, 표 카드 5개·규칙 카드 8개, 네 갈래 학습 기록
- 자유 악보 편집, 조표·붙임줄, 19개 오개념 비교 듣기
- 로컬 자동 저장·손상 백업·저장 불가 시 메모리 대체
- SVG 악보·임시표·시소·건반·공방 삽화, 외부 글꼴이나 라이브러리 요청 없음

`0` 키는 전체 화면을 전환합니다. 건반은 좌우 방향키로 이동하고 Enter 또는 Space로 누릅니다. 다른 조작은 Tab과 Enter로 사용할 수 있습니다. 붙임줄은 통로가 찰 때까지 누릅니다.

## 개발 및 검증

Node.js 22 이상에서 외부 패키지 설치 없이 실행할 수 있습니다.

```bash
npm run build
npm test
node scripts/tests-visuals.cjs
```

`src`의 구획을 `scripts/build.cjs`가 독립 실행 가능한 단일 `index.html`로 합칩니다. `dist/index.html`도 동일한 파일입니다. 사용자는 빌드하지 않고 배포된 단일 파일을 열 수 있습니다.

주소 끝에 `#test`를 붙이면 70개의 이론·콘텐츠·진행 자가검사를 볼 수 있습니다. 저장 및 오디오 검사는 Node의 별도 러너가 수행합니다. 자가검사 70개는 기기나 실제 청취 검사가 아닙니다.

## 확인한 범위

- 설계서 부록 C 원본 참조 검사: 1,760/1,760 통과
- 악보 2,591,406개, 붙임줄 변형 427,788개: 느린 기준 계산과 불일치 0
- 브라우저 순수 검사 70/70, 진행 결과 2,816조합, 전체 66개 복습 삽입 위치 통과
- 저장·오디오 및 SVG·건반 검사는 각각 별도 테스트 러너에서 확인
- Chrome 브라우저에서 66개 의뢰 전체, 7개 발견 장면, 납품과 단계 해금의 실제 클릭 흐름 확인
- 오답 2회 도움, 3문항 뒤 복습, 다음 날 복습, 새로고침 후 이어하기 확인
- 수동 2음 차례 연주와 붙임줄 1.3초 누르기 성공 확인
- 320×545 iframe에서 가로·세로 스크롤 없이 확정 버튼 302×52px 확인
- 도감, 자유 공방 편집·오개념 비교, 설정과 학습 기록 화면 확인

아직 확인하지 않은 항목: 실제 iOS Safari·Android 기기의 터치와 소리 청취, 블루투스 오디오, 음악 강사와 학습자 수업 검수. 설계 CH9의 해당 항목을 마쳤다고 표시하지 않습니다. 현재 버전은 기능 구현 및 브라우저 검증을 마친 v0.9입니다.

## 배포 준비

정적 `index.html`을 Vercel 프로젝트 루트에 배포하면 됩니다. `vercel.json`을 포함합니다. Vercel 배포는 별도 요청에 따라 진행합니다.

학습 기록은 접속한 주소의 브라우저 저장소에만 보관됩니다. 로컬 파일과 배포 주소, 다른 브라우저와 기기는 기록을 공유하지 않습니다. 개인 정보는 수집하지 않습니다.
